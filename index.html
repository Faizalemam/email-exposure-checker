How it works

Designed to check exposure without exposing you further.

01

Verify ownership

A one-time code is emailed to the address before the real scan runs.

02

Analyze safely

MX, SPF and DMARC checks run server-side. Optional breach-provider credentials remain in Script Properties.

03

Take action

Use verified findings to change passwords, enable 2FA and submit source-level removal requests.

Privacy by design

Your email should not become another data point.

The frontend does not save scans in localStorage or cookies. OTP data is temporary and expires automatically in the backend cache.
