How it works
Designed to check exposure without exposing you further.

      

        
01
Verify ownership
A one-time code is emailed to the address before the real scan runs.

        
02
Research safely
MX, SPF and DMARC checks run server-side. Gemini can use Google Search grounding for public-web research with citations.

        
03
Take action
Use verified findings to change passwords, enable 2FA and submit source-level removal requests.

      

    


    

      

        
Privacy by design
Your email should not become another data point.
The frontend does not save scans in localStorage or cookies. OTP data expires automatically. Gemini receives the verified address only when its API key is configured and the owner has authorized the scan.
