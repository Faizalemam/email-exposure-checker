How it works

Designed to check exposure without exposing you further.

01

Verify consent

The checker is intended for your own email addresses or authorized security assessments only.

02

Analyze safely

Public frontend validation happens locally. API credentials and sensitive logic remain off GitHub Pages.

03

Take action

Results should lead to practical steps such as password changes, 2FA, and source-level removal requests.

Privacy by design

Your email should not become another data point.

The static site does not save scans in localStorage or cookies. When a backend is added, data retention should remain opt-in and minimal.
