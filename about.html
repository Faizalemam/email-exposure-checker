About the project

Email exposure checks with safer defaults.

ITDelhi Email Exposure Checker is a privacy-first interface for helping users understand whether an email address they own—or are authorized to assess—may have security exposure.

What version 1 does

The current version provides a production-style static frontend with consent enforcement, email validation, masking in results, security recommendations, and a clean integration point for a secure backend API.

What it deliberately does not do

It does not pretend that an email is breached without verified data. It does not put private API keys into browser JavaScript. It does not automate account-recovery or password-reset flows to probe whether someone has an account.

Backend roadmap

  • Email ownership verification where appropriate.
  • Domain and mail-security posture checks.
  • Licensed or permitted breach-source integrations.
  • Public-web footprint results from permitted sources.
  • Removal guidance tied to the actual source of a finding.
  • Optional reports with minimal data retention.

Project principle

A privacy checker should not create a new privacy problem. Collect the minimum data needed, keep secrets server-side, and make every finding explainable and actionable.
